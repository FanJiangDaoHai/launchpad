## Context实体容器优化：List + Entity.ContextIndex swap-back

**问题**: `List<Entity>` 的 `Contains` 和 `Remove` 是 O(n)，HashSet 又有额外 GC。

**方案**: 回到 `List<Entity>`，在 `Entity` 上加 `ContextIndex` 字段，用 swap-back 实现 O(1) 移除。

**修改**:
- `Entity.cs`: 添加 `internal int ContextIndex { get; set; }`，默认 -1
- `Context.cs`:
  - `HasEntity`: 检查 `entity.ContextIndex >= 0 && m_Entities[index] == entity` → O(1)
  - `DestroyEntity`: swap-back 移除（最后一个移到当前位置）→ O(1)
  - `OnEntityReleased`: 检查 `ContextIndex < 0` → O(1)
  - `DestroyAllEntities`: 倒序 for，无需快照分配

**优势**: 零额外数据结构，无 GC 增加，Remove 从 O(n) 降到 O(1)。
